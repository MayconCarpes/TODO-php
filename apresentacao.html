1. CÓDIGO - CAMADA MODEL

Operações isoladas usando abstração PDO para segurança contra injeção.


// ARQUIVO: app/models/Tarefa.php
public static function listarPorUsuario($usuario_id) {
    // A Camada model esconde a complexidade do SQL
    $db = Database::getConexao();
    
    // INNER JOIN para buscar nomes de status e prioridade
    $stmt = $db->prepare("SELECT t.*, s.nome as status_nome, p.nome as prioridade_nome 
        FROM tarefa t 
        JOIN status s ON t.status_id = s.id
        JOIN prioridade p ON t.prioridade_id = p.id
        WHERE t.usuario_id = ? ORDER BY t.data_entrega ASC");
        
    $stmt->execute([$usuario_id]);
    return $stmt->fetchAll(PDO::FETCH_ASSOC); // Devolve o array pronto
}

2. CÓDIGO - CAMADA CONTROLLER

A Rota solicita que o Controller aja. Ele lê o model e passa para a View.


// ARQUIVO: app/controllers/TarefaController.php
public function index() {
    // 1. Quem está logado? (Se não tiver, é derrubado antes)
    $usuario_id = $_SESSION['usuario_id'];
    
    // 2. Chama o MODEL para pegar as Tarefas
    $tarefas = Tarefa::listarPorUsuario($usuario_id);
    
    // 3. Empacota os dados e joga para renderizar na VIEW
    $this->render('tarefa/index', [
        'tarefas' => $tarefas
    ]);
}

Protocolos ICE Ativos: Dados protegidos contra invasões no Banco.

HASHING NATIVO

O sistema NUNCA salva a senha original. Se o banco vazar, o atacante apenas verá um "Bcrypt Hash" incompreensível.

> (Ver código de Criptografia Abaixo ↓)

> CRIPTOGRAFANDO NO CADASTRO


// O Administrador cadastra um usuário novo
public static function cadastrar($nome, $email, $senha, $perfil) {
    $db = Database::getConexao();

    // 🔴 BLOQUEIO: Transforma "123456" em algo como "$2y$10$w8T9..."
    // Se a senha vazar, não serve de nada
    $hash = password_hash($senha, PASSWORD_DEFAULT);
    
    $stmt = $db->prepare("INSERT INTO usuario (nome, email, senha, perfil) 
                          VALUES (?, ?, ?, ?)");
                          
    $stmt->execute([$nome, $email, $hash, $perfil]);
}

[SYS] LÓGICA DE LOGOUT

O encerramento global retira todo acesso do usuário da memória do servidor.


// Classe AuthController ...
public function logout() {
    
    // 1. Limpa todas as chaves associadas a este computador
    session_unset();
    
    // 2. Oblitera a sessão global ativa no servidor PHP
    session_destroy();
    
    // 3. Redireciona violentamente para fora do sistema protegido
    $this->redirect('index.php?c=auth&a=index');
}

> EX de CRUD: Deletando um Status

Exemplo puro de roteamento destruindo um item de banco de dados.


// CAMADA CONTROLLER: AdminController.php
public function status_excluir() {

    // 1. O Controlador pega o ID na URL (/?c=admin&a=status_excluir&id=5)
    $id = $_GET['id'] ?? null;
    
    if ($id) {
        // 2. Chama a Camada Modelo repassando a Ordem
        Status::excluir($id);
    }
    
    // 3. Após explodir o dado, realoca o usuario para a lista principal
    $this->redirect('index.php?c=admin&a=status');
}

// CAMADA MODELO: Status.php
public static function excluir($id) {
    // A Camada modelo processa o código seguro anti-ruído.
    $db = Database::getConexao();
    $stmt = $db->prepare("DELETE FROM status WHERE id = ?");
    $stmt->execute([$id]);
}
